# StarPoint Companion

> 本页是 [README.md](README.md) 中使用说明部分的中文版，由 Claude（AI）翻译。两者内容相同；如有出入，以英文版为准。
> 工作原理、手机服务器需要的文件、电脑端路由、构建方法和 Android 版本说明只有英文版。

一个在手机上运行 GlobalPoint 服务器（`127.0.0.1:8000`）的 Android 应用，让修改过的国服游戏不用电脑就能玩：不需要 root、adb 或 Shizuku。
它是主 [README](../README.zh-CN.md) 中方式 1 的服务器部分。

**玩家：** 安装步骤见 [README](../README.zh-CN.md#快速开始手机或模拟器) 和安装指南（[方式 1](../docs/zh-CN/INSTALL.md#1-手机或模拟器)，
以及[从电脑复制](../docs/zh-CN/INSTALL.md#改从电脑复制数据)）。

应用的界面跟随手机的语言：手机设为中文时显示简体中文，否则显示英文。它和它的控制台也跟随手机的浅色 / 深色设置。

## 使用应用

**主界面**
- 一个就绪指示灯、**启动** / **停止**，以及 **打开本应用时启动服务器**（默认开启）。**绿色**：服务器已运行，游戏更新也是最新的，可以打开游戏。
  **黄色**：等待，服务器正在启动，或在控制台更改后正在重建游戏更新；这时打开的游戏会拿到旧的更新。**红色**：已停止。如果 8000 端口上有别的服务器在响应
  （例如通过 `adb reverse` 连接的电脑），界面会说明。
- **设置**（旧版本叫设置检查）：方式 1 的清单，每一行绿 / 黄 / 红，并附带修复按钮：游戏是否已安装；本应用和游戏的存储权限（会打开对应的设置页面）；
  OBB（在 Download、Downloads、Documents（以及往下一层的文件夹）或存储最上层查找，手机和 SD 卡都会找；3 个分卷，或用 `build_cn_obb.cjs` 生成的单个文件；
  旧的 1.4.203 单个 OBB 会显示红色：GlobalPoint 1.0 不支持它；浏览器加上的 " (1)"、"-1" 或 ".bin" 也可以，移动时会去掉），检查 SHA-256 后移到
  `starpoint_game`（是重命名，所以瞬间完成；只有跨存储时才复制）；投放文件夹里残留的零散游戏文件（有 OBB 时会移除，因为游戏启动前会把它们全部列一遍）；
  服务器的数据；漫画（可选，未添加时为灰色）；服务器。
  顶部的 **全部设置** 一次做完：请求本应用的存储权限，然后打开游戏的「所有文件访问权限」页面（你回来后自动继续），在同样的文件夹里找到 OBB 和数据包 /
  漫画包（按压缩包内容识别，不看文件名），说明将要做的事，然后检查并移动 OBB、移除残留文件、导入资源包（数据包只在服务器还没有数据、或版本与上次导入的
  不同时才导入）、启动服务器，并提出删除已导入的压缩包。中文图片包不会被它导入：请用 **导入资源包……**。
- **允许服务器在后台运行：** 请求 Android 让本应用不受电池优化限制，这样手机不会停掉服务器。授权之前一直显示。
- **控制台** 在应用内打开服务器的控制台（按返回回到应用）。**在浏览器中打开** 则用手机的浏览器打开。
- **导出存档** / **导入存档**（见[存档](#存档)）。
- **保存日志（用于反馈问题）：** 一个文本文件，包含游戏完整的崩溃报告（`cn_crash.log`）、服务器日志和游戏请求日志的末尾，以及应用和 Android 的版本。
  反馈问题时附上它。日志保存在应用的数据文件夹里，所以应用更新不会清掉它们（0.7.14 起）。
- 服务器运行时会显示一条通知；它的 **停止** 按钮可以结束服务器。

**游戏数据画面。** 服务器需要一些 APK 里没有的数据。有三种方法获取：
- **从电脑下载：** 输入同一 Wi-Fi 下 GlobalPoint 服务器的地址（例如 `192.168.1.20:8000`），勾选要带的内容：
  - **我的存档**（账号、角色、进度）
  - **游戏更新**（约 2 GB；仅当游戏仍需下载时）
  - **活动日程编辑**（约 175 MB；让控制台可以移动活动，并包含角色编辑器技能预览用的图片）
  - **控制台图片**（约 80 MB）
  - **漫画**（约 1.4 GB）
  - **完整游戏文件**（约 10 GB），用于游戏从未下载过文件的手机。见下文。

  手机上已有的文件会跳过，所以再按一次可以继续被中断的复制。电脑上的 **自制角色**（[docs/zh-CN/CUSTOM_UNITS.md](../docs/zh-CN/CUSTOM_UNITS.md)）
  不论勾选什么都会一起带过来；电脑上已删除的角色文件也会从手机上删除。它们的图片和语音是游戏更新，所以第一次请勾选 **游戏更新**。
- **导入资源包……** 导入在电脑上制作的资源包（见[资源包](#资源包)）。它打开系统的文件选择器，所以不需要存储权限。
- **选择压缩包……** 导入一个包含 `.database/` 和 `.cdn/` 文件夹（可选 `.env`）的压缩包，由 `companion/tools/make-data-zip.cjs` 生成。
- **检查文件……**：选任意文件并计算它的 SHA-256，然后说明它是不是 GlobalPoint 的下载（OBB 分卷、旧的单个 OBB、数据包（1.0 及更早）、漫画包、
  技能预览图片包、中文图片包、英文或中文版游戏 APK），是完整无损，还是损坏 / 不完整。

**完整游戏文件。** 新装的游戏会向服务器要完整的约 10 GB 下载，而 StarPoint Companion 不保存这些文件。**完整游戏文件** 把它们从电脑复制到游戏的
投放文件夹，即手机存储里的 `StarPoint/game`（138,000 个文件）。游戏（build 23 或更新）下次启动时会把它们移进自己的存储，并显示计数，之后就不需要下载。
- 复制需要为 StarPoint Companion 打开 **所有文件访问权限**（Android 11+；Android 6-10 为存储权限）。应用会带你到设置页面，你回来后自动继续。
- 游戏也需要 **所有文件访问权限** 和存储权限才能读取这个文件夹（Android 13+ 显示为 **音乐和音频** 以及 **照片和视频**），但它从不请求。
  **允许世界弹射物语的「所有文件访问权限」** 按钮会打开它的设置页面。
- 复制需要约 10 GB 可用空间，游戏移入文件时还需要差不多同样多（大多数手机上从共享存储移到游戏的私有存储是复制）。
- 复制期间请保持游戏数据画面打开：它会让屏幕和 Wi-Fi 保持唤醒。离开的话 Android 可能暂停复制；再按一次下载即可继续。

OBB 方式（方式 1）不需要这次复制就能给游戏它的文件。

### 资源包

用于电脑不在同一 Wi-Fi 下的手机。在电脑上用 `scripts/build_pack.cjs` 制作，复制到手机（例如下载文件夹），用 **导入资源包……** 导入。应用按资源包的
内容识别它，检查可用空间，带进度解压（跳过已存在且大小相同的文件，所以可以续传），然后提出删除资源包。

- **数据包**（自 GlobalPoint 1.0 起 221 MB，不再包含 3 分卷 OBB 里已有的游戏更新；[下载](../docs/zh-CN/INSTALL.md#下载)里有，
  `starpoint-data.zip`，百度网盘上叫 `StarPoint-数据包-1.0.zip`）：除存档和完整游戏文件外 **从电脑下载** 带的一切。
  - 导入时服务器会停止。数据包从不动存档和账号文件。
  - 它替换整个文件夹，所以手机上之前的日程修改会被移除：手机从资源包的状态开始。
- **中文图片包**（约 1.5 GB，`starpoint-chinese-art-pack.zip`，百度网盘上叫 `StarPoint-中文图片包.zip`）：国服被 GlobalPoint 换成英文的原图，用于中文游戏语言
  （[CHINESE.md](../docs/zh-CN/CHINESE.md)）。在数据包之后导入，然后停止并重新启动服务器。
- **漫画包**（约 1.4 GB）：服务器的漫画文件夹。导入时服务器继续运行。中文漫画包（目前还没有发布）会放在它旁边的 `comics_zh`。
- **技能预览图片包**（约 35 MB，`starpoint-skill-preview-art.zip`）：只用于数据包早于 0.8.98 的手机。1.0 的数据包已经包含这些图片，不需要它。

### 存档

存档是 StarPoint Companion 的数据文件夹 `files/data/.database`（`wdfp_data.db` 加上 JSON 状态文件），不在游戏应用里。
- **导出存档** 把 `.database` 写成一个压缩包，存到你选的位置（下载、网盘……）。服务器运行时，数据库取自一致的快照；停止时按原样复制文件。导出失败会删除写了一半的文件。
- **导入存档** 先确认，然后停止服务器，用这样的压缩包替换 `.database`（旧的保留为 `files/data/.database.old`），再重新启动服务器。
- **adb，不用 root：** release 版 APK 特意设为可调试，所以可以这样做（先停止服务器）：
  ```bash
  adb exec-out run-as org.globalpoint.companion tar -cf - files/data/.database > companion-save.tar
  ```
- 控制台的 **玩家** 页面可以下载游戏看到的玩家存档（JSON）。方便查看，但它不是数据库备份。
