# 用技能标签页制作技能

> 本页是 [SKILL_GUIDE.md](SKILL_GUIDE.md) 的中文版，由 Claude（AI）翻译。两者内容相同；如有出入，以英文版为准。

> 由 Claude（AI）在 Claude Code 会话中编写，工作方式由仓库作者决定。

角色编辑器的 **技能** 标签页（控制台 → **角色编辑器** → 选一个角色 → **技能**）可以修改角色的技能做什么：打在哪里、多强、看起来怎样、给什么强化。本页是入门指南：
技能需要什么、什么是可选的、可能出什么问题，以及一些可以照抄的做法。标签页的每个按钮和设置都列在 [UNIT_EDITOR.zh-CN.md](UNIT_EDITOR.zh-CN.md#技能标签页)。

**保存前就能看到技能的样子。** **▶ 预览技能** 在控制台上播放它：角色的姿势、特效、每个范围命中的位置，以及在假想目标上的命中。数值（实际造成多少伤害、
战斗中强化怎样叠加）只能在游戏里实际使用来测试。

**随便尝试也不会弄坏存档。** **▶ 预览技能** 在保存前播放你的技能，编辑器拒绝保存游戏读不了的东西，**恢复为游戏原样** 会还原角色自己的技能。

下文的「已测试」指在战斗中确认有效；没有测试过的都会注明。

## 先要知道的两件事

- **时间以帧计算：60 帧 = 1 秒。** 所以 120 = 2 秒，720 = 12 秒。
- **技能是一列指令，从上往下执行。** 角色使用技能时，游戏会先自动播放它平常的技能姿势、闪光和特写图片，并停住弹球 1 秒。然后执行这个列表。技能标签页只编辑这个列表；
  姿势、特写图片和语音保持角色自己的。

（只在手动放置时需要：位置使用战斗自己的单位。场地约 1500 宽、2000 高，Y 为正表示在屏幕上更 **靠下**。）

## 最简单的技能

- **什么都不做的技能** 也可以：技能槽清空，特写播放，其他什么都不发生。国服游戏自己就有一个这样的技能。
- **造成命中的技能** 需要一条指令：一个里面带 **伤害** 的 **攻击范围**。按 **+ 添加…… → 攻击范围**：它已经准备好，带圆形范围、显示它的特效和里面的伤害。已测试。
- **给强化的技能** 也只需要一条指令：对「该角色」的 **强化 / 弱体效果**。要强化整个队伍，把它放进设为「队伍」的 **查找群组** 里，并把强化的目标设为「该群组」。已测试。

一个准备好的攻击范围在列表里的样子：

```
攻击范围              打在哪里：形状、大小、位置、持续多久、多久一次
  出现时：
    特效              你看到的图像（可选：没有它范围也会命中）
  每次命中时：
    伤害              每次命中对敌人造成什么
```

## 基本组成

| 指令 | 需要吗？ | 作用 |
|---|---|---|
| **攻击范围** | 要命中任何东西就需要 | 造成命中的区域。**圆形**（半径）、**矩形**（宽 × 高）或 **扇形**（半径和角度）。它本身是看不见的。 |
| **伤害**（在范围的「每次命中时」里） | 要造成伤害就需要 | 每次命中多强（按技能等级的低值和高值）、属性（角色自身的最安全）、破防槽伤害和获得的 FEVER。它的 **命中特效** 只是打在敌人身上的火花：选「无」仍造成全额伤害。 |
| **特效** | 不需要 | 一段动画。放在范围的「出现时」里，显示范围打在哪里。 |
| **停止弹球** | 不需要 | 技能播放时让弹球停住。国服大多数技能都以它开头；没有它弹球会继续移动。 |
| **等待**、**重复** | 控制时机 | **等待** 在若干帧后执行里面的内容。**重复** 立即执行里面的内容，然后每隔若干帧再执行，共指定的次数。 |
| **强化 / 弱体效果** | 不需要 | 攻击提升、伤害提升、耐性等，给角色、队伍或被命中的敌人。 |
| **镜头震动**、**治疗**、**FEVER / 技能槽** | 不需要 | 如其名。 |

## 什么时候执行

没有单独的「何时」设置：**指令在列表中的位置决定它什么时候执行**，在查找或范围里时，还决定它作用于 **谁**。最上层的指令在技能开始时（1 秒特写之后）立即执行。
在其他指令里面的指令会晚一些执行，或执行多次：

| 把指令放在…… | 它会执行 | 用强化 / 弱体效果的例子 |
|---|---|---|
| **最上层** | 一次，技能开始时 | 技能发动时强化角色 |
| **等待** 里 | 一次，在那么多帧之后 | 攻击之后才生效的强化 |
| **重复** 里 | 一次又一次：立即，然后每隔若干帧 | 多次给予的强化（会叠加，直到最大层数） |
| 攻击范围的 **出现时** 里 | 每次出现一个范围时一次（5 个范围：5 次） | 很少用于强化；多用于特效 |
| 攻击范围的 **每次命中时** 里 | 每次范围命中一个敌人时，每个敌人一次 | 对 **「命中目标」** 的弱体：只有范围碰到的敌人会被施加 |
| **查找群组** / **查找最近的** 里 | 对找到的每一个各一次 | 强化每个队员；弱化最近的敌人 |
| **如果生命值 ≥ X %** / **如果在 FEVER 中** 里 | 只有当时条件成立才执行（否则执行另一个分支） | 克菈菈的技能：生命值 60 % 以上时攻击提升，否则护盾和治疗 |
| **随机选择** 里 | 随机执行其中一个选项 | 随机加成 |
| **弹球命中时** 里 | 一段时间内，每次角色的弹球命中敌人时 | 对弹球碰到的每个敌人施加弱体 |

## 强化和弱体：设置

**强化 / 弱体效果** 指令有这些设置。有些显示游戏自己的名称，写在括号里。

- **目标**：谁获得它。「该角色」，或者按指令所在位置，「该群组」（在查找里）或「命中目标」（在「每次命中时」里）。
- **状态**：哪种强化，以及它的数值。例如攻击提升（`ACAttackPoint`）有 **帧**（持续多久：720 = 12 秒）、**数量**（0.4 = +40 %；负数则降低）和 **最大叠加层数**。可以一次给好几种。
- **生效几率**：1 = 一定生效。
- **已存在时也再次赋予**：关 = 第一个还在时，第二个不起作用；开 = 叠加，直到最大叠加层数。
- **可被解除**：清除强化的技能能否去掉它。
- **可赋予的对象**：角色、队伍或两者皆可。保持它原来的值：错误的值会让游戏报错。

两个例子：
- **对斩击碰到的每个敌人施加一次弱体：** 攻击范围 →「每次命中时」→ 强化 / 弱体效果，目标 **命中目标**，「再次赋予」关。
- **范围每次命中时强化角色：** 同样的位置，但目标设为 **该角色**，最大叠加层数大于 1。

## 逐步操作

1. **选角色** 并打开 **技能**。从它自己的技能开始，或按 **以其他角色的技能为起点** 复制一个。
2. **添加攻击范围**（列表末尾的 **+ 添加……**）。设置它的 **形状和大小**、**位置**（附着在角色或它的弹球上，距离多远）、**持续多久** 和 **命中间隔**。
3. **选它的特效。** 在特效卡片里，适合范围形状的特效排在最前面；**▶ 查看特效** 可以播放。保持 **让特效与攻击范围保持一致** 开启，这样图像与范围大小一致。
4. **设置伤害**：它的低值和高值，以及命中特效。
5. 可选：先 **停止弹球**，用 **等待** 控制时机，加强化，或用 **重复** 打出节奏。
6. 按 **▶ 预览技能** 观看：角色的姿势、特效、命中位置的轮廓，以及在假想目标上的命中。
7. **保存。** 有红色提示时不能保存；先修好它们。然后关闭并重新打开游戏：它会在标题画面下载更新。
8. **技能和技能+ 都要检查。** 它们是分开的：改了一个，另一个保持原样。技能槽在 **数值** 标签页。

## 做法示例

**角色周围的一次大爆炸：** 攻击范围，圆形，半径 250，附着在角色的弹球上，持续 40 帧，命中一次（`CalculatedUsingMaxNumOfHits` 1）。特效 *air blast*（保持一致会把它的缩放设为 5）。
伤害 5 到 10，命中特效 Coarse。

**弹球前方的斩击：** 攻击范围，矩形 300 × 120，朝向弹球移动的方向（方向 EF），向前移 150（偏移 Y −150）。特效 *claw horizontal*，缩放 1.5。

**5 秒内每 20 帧一次、随机角度的爆发：** 一个重复（每 20 帧，15 次）→ 里面一个随机选择，有四个选项（权重各 1），每个是一个旋转 0°、90°、180° 和 270° 的特效。
伤害方面，再加一个持续 300 帧、每 20 帧命中一次的攻击范围，让命中和爆发保持同步。

**强化整个队伍：** 查找群组，设为「队伍」→ 里面一个对「该群组」的强化 / 弱体效果：攻击提升（`ACAttackPoint`），帧 720，数量 0.3（+30 %），最大叠加层数 1。

**召唤其他角色的协力球：** **+ 添加…… → CreateSummonsMultiball**，然后在它的第二个设置里填协力球的编号。协力球的编号是它角色的编号加一位数字（黄金船 113001 → 1130011；
梅米 311002 → 3110021、3110022、3110023）。国服的每一个都列在 [research/skill-commands.zh-CN.md](research/skill-commands.zh-CN.md)。第三个设置是它停留多久（国服大多数技能里是
9000 帧 = 150 秒）。已测试：克菈菈召唤了其他角色的协力球，并且它正常行动。未确认：它用谁的数值。预览不显示协力球。

## 需要注意的地方

**这些可能让游戏报错，请避免：**
- **命中特效 Fine、Coarse、Slash 和 Critical slash 搭配属性「无」。** 这四种没有无色版本，命中没有属性时游戏会报错停止。用它们时，让伤害的属性保持 **角色自身的**，
  或一个真正的属性。（「无」是否算作没有属性没有测试过：避开这个组合就好。）
- **国服技能从未用过的指令**（只在不受限模式下提供，标为「未测试」）：可能什么都不做，或让游戏崩溃。
- **手动编辑的 id**（进阶和不受限模式）：id 是一条指令给「该范围」「命中目标」或「该群组」起的名字，让它里面的指令可以指向它。编辑器不会保存没有任何指令命名过的 id；
  默认模式下它们是隐藏的，所以不会出现这种情况。

**这些没问题，但会让人意外：**
- **图像和命中是分开的。** 把特效放大不会让范围命中更多，反之亦然。保持一致（默认开启）会让图像与范围大小一致，范围下面的「绘制：」行会在两者不一致时警告。
  没有扇形的共用特效，所以扇形上的图像看起来是圆的。
- **大多数特效只播放一次。** 显示得更久不会重复：播放一次就没了。要重复爆发，把特效放进 **重复** 里，或放进范围的「每次命中时」里。（少数特效会循环，例如
  whirlwind slash：它们显示多久就播放多久。）
- **你看到的大部分常常是命中特效。** 每 20 帧命中一次的范围，每次命中都会在每个敌人身上显示命中特效（已测试：5 秒的范围上 Coarse 出现了 15 次）。
- **技能的名称和介绍不会自己变。** 角色页面仍然描述旧技能，直到你在技能标签页顶部修改 **名称** 和 **介绍** 框。

## 手机和分享

- **电脑：** 保存的技能会进入服务器生成的游戏更新。关闭并重新打开游戏即可获得。
- **手机：** 从你的电脑复制（**从电脑下载**）的手机也会获得这些技能。手机自己的服务器需要 **StarPoint Companion 0.8.92 或更新** 才能把编辑过的技能发给游戏。
- **配置文件：** 下载的配置文件带有角色的技能；导入时会放回去。
