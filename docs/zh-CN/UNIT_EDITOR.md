# 角色编辑器（控制台）

> 本页是 [UNIT_EDITOR.md](../UNIT_EDITOR.md) 的中文版，由 Claude（AI）翻译。两者内容相同；如有出入，以英文版为准。

> 由 Claude（AI）在 Claude Code 会话中编写，工作方式由仓库作者决定。

在控制台里修改角色的能力和技能做什么，以及它的数值：菜单里的 **角色编辑器**（`/unit-editor`）。适用于每个国服角色和自制角色（[CUSTOM_UNITS.md](CUSTOM_UNITS.md)）。
角色 id 不会变，所以存档永远不会有风险。

## 能编辑什么

- **能力标签页**：每个能力（1-6）和队长特性，按行显示。每一行是一个效果：
  - **仅当**：最多 3 个条件（「该角色为水属性」「队伍中有 6 个以上水属性角色」「生命值在 80% 以上」……）；
  - **种类**：*when*（某件事发生的那一刻）或 *while*（某种状态持续期间），以及触发（「FEVER 开始时」「使用技能时」「每 X 秒」……），只显示该触发用到的栏位
    （每 N 次、秒数、生命值 %、对象、次数（上限）、冷却）；
  - **执行**：效果、它的目标和数值（数值、持续时间、最大层数……）。

  队长特性的行还有 **显示**：总是、仅觉醒前、或仅觉醒后（数值在觉醒时变化的地方，游戏会为每种情况各留一行，例如巴拉克觉醒前「+ 55 %」、觉醒后「+ 70 %」）。

  行可以删除、添加（每个能力或队长特性最多 **8 行**；国服自己的角色最多用到 6 和 8 行），或从其他角色复制。能力上的 **恢复为游戏原样** 会还原它自己的行。

  每个能力下方会按角色页面自己的措辞显示 **游戏中** 的说明，取其范围的两端（第一个玛纳节点和全部六个；队长特性取觉醒前后）。条件和触发相同的行合成一句，
  效果用「&」连接，和游戏一样；新的触发另起一段。说明由游戏自己的文本片段（UI 字符串表）按客户端的方式填入：覆盖国服 4,928 条能力和队长特性行中的 92%，
  亚美莉亚的所有行都与模拟器上她的角色页面逐字一致（属性显示为 ⟨水⟩，游戏里那里画的是图标）。还无法用游戏措辞表达的行（切换技能、协力球组、角色专属强化）
  会注明；勾选那里的 **无法显示游戏措辞时使用编辑器的措辞**，会用编辑器自己的句子代替那一行（标为「编辑器的措辞」）；保存后角色页面无论如何都显示游戏的文本。
- **数值标签页**：Lv 1/10/80/100 的生命值 / 攻击力、技能槽（技能和技能+），以及每一行的每个最小 → 最大值（与能力标签页是同样的数值）。
- **详细信息标签页**：名称、称号、介绍、队长特性名称、**职业** 和 **职责**。职业（剑士、格斗、射击、辅助、特殊）也决定角色的强化弹射攻击，并影响以职业为对象的能力；
  职责（输出、坦克、治疗、辅助者、妨碍、均衡）只是标签、图标和列表筛选。没有数值依赖于它们（客户端：SpecialityTypeTools、StanceLogic）。剧情、图鉴等画面保留它们自己的文本。
- **技能标签页**：技能和技能+ 的名称和介绍，以及它们做什么，来自它们的脚本（见下文）。

**最小 → 最大**：能力从第一个玛纳节点到第六个（游戏按直线填充中间各级；没有节点时能力不生效）；队长特性从觉醒前到觉醒后；技能槽从技能等级 1 到最高。
数值以直观的单位显示（%、秒、点、连击）；数据表里存的是 × 100,000，编辑器双向换算。单位未知的效果显示存储的数字「（游戏数值）」。

这里不能编辑的：能力文本（游戏根据各行自己生成，所以总是一致）、属性和稀有度（服务器保留自己的副本）、玛纳板的消耗。

## 技能标签页

第一次用？先看 [SKILL_GUIDE.md](SKILL_GUIDE.md)：技能需要什么、可能出什么问题，以及可以照抄的做法。

技能是一列 **指令**，从上往下执行。标签页上的每张卡片是一条指令。缩进在另一张下面的卡片在它里面执行：**等待** 之后、**攻击范围** 出现时、它的每次命中时、
对 **查找** 选出的每个角色，或在 **如果** 的某个分支里。最常用的指令：

| 指令 | 作用 |
|---|---|
| **攻击范围** | 造成命中的区域：形状（圆形、矩形或扇形）、大小、位置（在角色或它的弹球上，距离多远，朝哪个方向）、持续多久、多久命中一次。 |
| **特效** | 一段动画：游戏的共用特效之一（按角色的属性绘制），或某个角色自己的，放置方式和范围一样。 |
| **伤害** | 放在范围的「每次命中时」里：命中谁、属性、多强（倍率）、破防槽伤害和获得的 FEVER。 |
| **强化 / 弱体效果** | 给角色、队伍或找到的群组：哪种强化（攻击、技能伤害、属性耐性……）、多久（帧）、多少、最大层数。 |
| **停止弹球**、**移动弹球** | 技能播放时弹球做什么。 |
| **等待**、**重复** | 时机。等待：里面的内容在若干帧后执行。重复：立即执行，然后每隔若干帧再执行，共指定的次数。 |
| **随机选择** | 随机执行其中一个选项。每个选项有 **权重**（1 和 1 = 各一半的机会）。放在重复里时每次都会重新选。 |
| **查找群组**、**查找最近的** | 选出队伍、所有敌人、最近的敌人……；里面的指令作用于它们。 |
| **镜头震动**、**治疗**、**解除效果**、**FEVER / 技能槽** | 如其名。 |

**编辑：**
- 直接在卡片上 **修改** 任何设置。属性、群组、「可赋予的对象」和附着对象是下拉菜单；角度以度为单位。随技能等级增长的数值有两个框：技能等级 1 和最高等级。
  国服大多数技能不改的设置收在 **更多** 下面。
- 每个区块末尾的 **+ 添加……** 添加一条指令，以最常见的形式准备好（新的攻击范围会自带特效和伤害）。每张卡片都有 **↑ ↓ 复制 移除**。
- **以其他角色的技能为起点** 复制另一个角色的技能或技能+ 作为起点。**恢复为游戏原样** 还原角色自己的技能。
- 技能姿势、特写图片和语音不在这个列表里：它们保持角色自己的。
- 每个技能顶部的 **名称** 和 **介绍**：角色页面显示的文字（每个框下面灰色的是游戏原文）。游戏不会根据脚本生成它，所以改了技能做什么之后，也请修改介绍。
  介绍可以有多行（按回车），国服自己的有些也是这样；名称不能为空。配置文件会把这些文字和技能的其他部分一起带上。

**保存前检查你的技能：**
- **▶ 预览技能** 按你编辑的样子播放整个技能：角色的技能姿势、特效、每个范围命中区域的轮廓、弹球的移动、镜头震动，以及在假想目标（一个十字）上的命中。
  可以播放、暂停，或拖动滑块到任意帧。
- 特效卡片上的 **▶ 查看特效** 播放那一个特效，按它有的每种属性颜色，并用虚线画出它所在范围的轮廓。
- 攻击范围下面的 **「绘制：」行** 说明它的特效在那里看起来怎样、持续多久，并在图像与实际命中不一致时警告：矩形上的圆形图像、比范围大很多或小很多的图像、
  扇形（没有扇形的共用特效），或比范围停止命中早很多就结束的图像。
- **让特效与攻击范围保持一致**（默认开启，在标签页顶部）：每当你修改范围或它的特效时，调整范围特效的大小。特效列表会优先推荐适合范围形状的特效。
- **运行时间**：技能运行多久，以及弹球何时被停住。
- **每个敌人的命中次数**：每个伤害下面，它的范围能命中同一个敌人多少次，以及这些命中的总伤害倍率（克菈菈：15 次 × 0.533 = 每个敌人 8）。根据设置算出，不是在战斗中测得的。
- **属性提示**：伤害的命中属性与它的特效绘制属性不同时。

**模式**（与其他标签页相同的模式选择）。国服自己的每个技能都能通过所有模式。
- **默认**：只有国服技能用过的指令、选项和特效，最多 60 条指令、8 个攻击范围和 10 层嵌套。（作为起点的技能可以保持原来的大小：国服最大的有 149 条指令和 16 个范围。）
- **进阶**：更大的上限（200 条指令、20 个范围、16 层），并在「更多」下显示 id。id 是一条指令给「该范围」「命中目标」或「该群组」起的名字，让它里面的指令可以指向它；
  默认模式下它们是隐藏的，会自动为你按名称选择。
- **不受限**：还包括国服从未用过的指令和选项（标为未测试，可能让游戏崩溃）、任何特效、以文本输入的任何值（「{ }」），上限 1000 / 100 / 40。
- **任何模式下都会拒绝**：游戏读不了的东西（错误类型的值、未知指令），以及指向上面没有任何指令命名过的 id 的指令。

**保存**：技能和其他修改一样进入游戏更新：关闭并重新打开游戏即可获得。**从电脑下载** 会把编辑过的技能复制到手机，**配置文件** 会带上角色的技能（导入时放回去）。

### 工作原理（细节）

- **文件**：技能是角色技能行所指向的脚本文件。保存时写入一个新文件
  `skills/battle/action/skill/action/custom/<角色>_<1|2>_<哈希>`（在自制角色文件夹里），每次修改都用新名字（这样游戏不会保留旧副本），并让技能行指向它。
  游戏更新会带上修改文件用到的每个已保存脚本。保存时，这个角色不再被使用的旧脚本文件会被删除。缺少技能脚本的配置文件会被拒绝。
- **技能发动时发生什么**：游戏播放精灵的 `skill_ready` 序列（技能姿势），显示技能闪光和特写，停住弹球 60 帧，然后执行脚本。预览会模仿这一过程。
- **特效大小**：国服每个共用特效在每个缩放下以固定大小绘制，这是从国服自己的技能测得的：例如 *spread* 在缩放 1 时是半径 42 的圆，*air blast* 50，*laser*
  是 133 × 1333 的光束，*claw horizontal* 200 × 80。所以「绘制：spread 缩放 6 ≈ 半径 252 的圆」。警告阈值是大或小 20 %。角色自己的特效没有测得的大小
  （「大小未知」）；国服的扇形技能用的是角色自己的图片。
- **特效时长** 从每个特效的时间轴文件读取（例如 *spread* 播放 40 帧，然后它的「end」持续到第 68 帧），所以「绘制」行可以说「持续 40 帧」或「与范围持续时间一样长」。
- **运行时间** 把等待、攻击范围、特效和弹球移动加起来（重复按间隔 × 次数计算）。附着在弹球上的东西持续到弹球停止之后时会有提示（那时它会随弹球移动，
  克菈菈的旋风就是这样设计的）。
- **每个敌人的命中次数** 来自范围的命中间隔、最大命中次数和「消失」设置。
- **预览** 是舞台，不是战斗：没有敌人（敌人群组也站在假想目标上，它位于第一个范围到达的地方），除非移动弹球让它移动（向上），否则弹球不动，「如果」只显示
  第一个分支。每个范围按命中间隔命中目标，直到最大命中次数，每次都执行「每次命中时」，所以伤害的命中特效会显示在那里。角色按战斗中那样放大 × 6 绘制
  （特效和范围用战斗单位）。命中特效 Fine 和 Coarse 内置在游戏应用里（游戏 APK 中的 `assets/bundle.zip`）；服务器从 `CN_GAME_APK` 或 `apk/` 文件夹里最新的
  `.apk` 读取它们，没有的话用该属性颜色的爆发图代替。与战斗录像对比（2026-11-16）：air blast、每 20 帧命中一次的 5 秒范围的 15 次 Coarse 命中，以及技能闪光都一致。
- **▶ 查看特效** 按游戏的方式播放游戏自己的动画文件，每秒 60 帧，先用角色自己的属性，并按特效的序列播放。

## 分享配置

**已编辑的角色和配置**（页面顶部）列出编辑器改过的每个角色。**下载** 一个、勾选的或全部：一个 JSON 文件，包含它们的修改。它本身就是一个角色修改文件，所以有两种用法：
在本页 **导入配置文件**（每个角色的修改成为它的编辑器文件，经过与保存相同的检查；不存在的角色的配置、其他角色的行或游戏读不了的行会被拒绝），或者放进自制角色文件夹的
`changes/`。自制角色的修改在它们自己的文件里，不会列出。

文件的格式（哪些表、行和列，以及技能脚本怎样一起携带）见 [KIT_FORMAT.md](KIT_FORMAT.md)，供想在其他国服服务器或分支上使用配置的人参考。

## 防护规则

- **默认模式** 只提供国服自己的角色用过的触发（每个国服角色的 4,928 条能力和队长特性行）：它们的触发、条件、条件 + 触发的组合和「对象」选项。**任何效果都可以
  搭配这些触发，不会有警告**：游戏触发后，不论是什么触发的，都以同样方式施加效果（已测试：「每 X 秒」+「连击 +」，没有国服角色这样搭配，在战斗中有效）。
- **进阶模式**（模式选择）保持在国服角色用过的条件、触发、「对象」和效果之内，但可以任意组合：例如「不在 FEVER 中」搭配「该角色攻击力提升期间」或「协力球存在期间」，
  没有国服角色这样搭配。这样的行会有提示（「国服角色没有这样一起用过」），但不会被阻止。
- **不受限模式** 还提供国服从未用过的条件、触发、「对象」和效果（标为「未测试」）。它们显示「未使用的触发 / 条件 / 效果：可能无效或让游戏崩溃。」决定一行能否生效的是触发。
  （模式会记在浏览器里。）
- **角色专属强化**（「Energy Drain」「Cursed」……：国服有 19 种，各自绑定一个角色）只有自己的配置用到它们的角色才能使用；在两种模式下，指定其他角色专属强化的行都会被拒绝。
- **总是拒绝**：矛盾（排除了该行自己触发的条件，例如「不在 FEVER 中」+「FEVER 中」；队长同时是两种属性；生命值高于 X 又低于更低的 Y）、在没有「对象」的触发上用
  「对触发的角色」（例如「每 X 秒」：没有人触发它；这时不提供这个目标），以及游戏读不了的东西（未知代码、该填数字的地方填了文字）。修好之前保存一直是灰色。

如果角色页面显示了你的文字，说明游戏读取了这一行。新的组合打一场快速战斗就知道是否有效（战斗代码和说明代码是分开的）。

## 保存并放进游戏

- **保存** 只写入与游戏原版不同的行：国服角色写入 `assets/custom_units/changes/unit-editor-<id>.json`（一个角色修改文件，
  [MAKING_UNITS.md](MAKING_UNITS.md#手动修改已有角色)）；自制角色写入它自己的文件。服务器会立即重建国服游戏更新。
- **关闭并重新打开游戏**：它会在标题画面下载更新。
- **只有手机（没有电脑）**：StarPoint Companion 的 **控制台** 里也有编辑器。在那里保存会在手机上写入修改文件，手机会重建自己的游戏更新。
- **有电脑时**：手机用 **从电脑下载** 获得电脑上的修改（修改文件总会一起带来）。这次复制会用电脑上的修改替换手机自己的，所以要么只在一边编辑，要么先在手机上
  **下载** 配置文件，再在电脑上导入。
- **将角色恢复为游戏原样** 删除编辑器的修改文件并重建。这个角色的其他修改文件和按日期平衡的配置会列在页面上，保持不变（修改会叠加在按日期的配置之上）。

## 装备

页面顶部的 **角色 / 装备** 切换用同样的方式编辑装备（国服全部 436 件），防护规则、保存、配置文件和恢复都一样（`/unit-editor?armament=<id>`）。

- **能力标签页**：装备的每个能力是一个 **效果**（最多 **10** 个，这是游戏自己的上限：槽位 0-9；国服最多用到 10 个）。一个效果最多有 **3 个版本**，每个都有
  **起始等级**：游戏对每个效果使用已达到的最高装备等级对应的版本（例如乌贡瓦萨拉：3 级起技能伤害 + 50 %，5 级起 + 100 %）。两个版本不能是同一等级。国服最多用 2 个版本。
  **游戏中** 显示整件装备在 1 级和最高等级时的说明。
- **数值标签页**：游戏列出的各等级的生命值 / 攻击力（1 级，大多数还有 3 级和 5 级），以及每个最小 → 最大值。数值从装备 1 级缩放到它的最高等级（5，有 51 件是 1）。
- **详细信息标签页**：名称和介绍。
- **只有 1 级的装备** 无法缩放：每个最小值都必须等于最大值（否则客户端会报错停止），所以编辑器会拒绝两者不同的行。
- 角色专属强化只有在装备自己的行用到时才有效，和角色一样。

保存为 `changes/armament-editor-<id>.json`，包含这些表（来自国服 1.8.1 客户端的解析器）：`master/item/equipment`（名称在第 1 列，介绍第 7 列，最高等级第 8 列）、
`master/item/equipment_status`（`<id>/<等级>`：hp、atk）和 `master/ability/ability_soul`（每个效果版本一行：槽位、学习等级、种类，然后是角色能力的布局）。
服务器不保存装备数值或能力的副本（`src/lib/equipment.ts` 只保存持有者、等级、强化和堆叠），所以只靠更新就能改变它们。

**已测试（2026-11-04，StarPointTest 模拟器，StarPoint Companion 0.7.4）：** 装备编辑器的修改文件放在手机的 `custom_units/changes/`；手机重建了更新（1.4.966，
两张装备表都在里面），游戏接受了它（7 MB）。在最高等级时，星芥二叉枪的页面显示「Protostar Bident (Edited)」和「该角色攻击力 + 90 %」（原为 + 70 %），
灼钺显示「Infernal Axe (Edited)」和「协力球生命值 + 40 %」（原为 + 20 %）。游戏的装备页面列出已达到的版本，并把之后的版本标为「Awakening Lv5」。
之后移除了这些文件（更新 1.4.967，恢复游戏自己的行）。

## 中文和按国服名称搜索

- **按国服名称搜索**：角色和装备框（以及复制时的「来源角色」）也能用国服自己的中文名称和称号（瓦格纳、狱炎龙王……）找到角色，用国服名称（百物语……）找到装备，
  两种语言都可以。它们来自国服自己的 `character_text` 和 `equipment` 表，所以每个国服角色和装备都有（自制角色只有它们自己的名称）。
- **语言：** 页面跟随控制台的语言（侧边栏的 **控制台语言**）。模式旁边的 **中文** / **English** 切换只改变本页，记在这个浏览器里。它会重新加载页面，
  所以有未保存的修改时会先询问。中文模式下：
  - 页面的标签、提示、消息以及游戏代码的白话说明都是中文，使用国服自己的游戏术语（角色、装备、能力、技能槽、强化弹射、协力球、合击、玛纳板、觉醒……）；
  - **游戏中** 用国服自己的中文措辞显示每个能力（国服的 `ui_string` 片段，按与英文相同的方式填入），例如「⟨火⟩角色攻击力 + 75 %」；
  - 角色的标题显示它的国服名称和称号，后面是英文名。
- 保持原样的：角色自己的文本（名称、称号、介绍、技能文本：详细信息和技能标签页按游戏语言显示游戏自己的文本：英文，或游戏设为中文时国服自己的中文；你在那里输入的内容，不论哪种语言，就是游戏显示的内容）、技能脚本
  指令名（`CreateHitArea`……）、特效文件路径，以及国服角色从未用过的代码的客户端原名（不受限模式）。种族分组（龙、兽……）显示代码：国服的表里没有它们的中文。
- 中文文本在 `web/public/js/unit-editor-zh.js`：一张英文字符串 → 中文的表，加上带数字或名称的文本的模式。没有条目的文本保持英文，所以缺一行永远不会让页面出错；
  要翻译它，把英文作为键加进去。
