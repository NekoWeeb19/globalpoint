# 自制角色（国服应用）

> 本页是 [CUSTOM_UNITS.md](CUSTOM_UNITS.md) 的中文版，由 Claude（AI）翻译。两者内容相同；如有出入，以英文版为准。

国服应用的新角色，只用游戏数据和文件制作（不改游戏代码）。本页是给玩家的：把别人做的角色放进你的游戏、发给自己、以及移除它。制作方法和文件格式见
[MAKING_UNITS.zh-CN.md](MAKING_UNITS.zh-CN.md)；它们是怎样被发现可行的，见 [research/new-units.zh-CN.md](research/new-units.zh-CN.md)。

## 把自制角色放到你的设备（或模拟器）上

方式 1-3 就是安装指南[选择安装方式](INSTALL.zh-CN.md#选择安装方式)里的那些。

**需要：** 别人做好的角色（见 [MAKING_UNITS.zh-CN.md](MAKING_UNITS.zh-CN.md)）：一个文件夹，里面有 `custom_unit.json`（角色文件）、`art_files.json` 以及角色的
图片和语音。自制角色从不包含在 APK、数据包或 OBB 里：要你自己在电脑上添加。

### 有电脑服务器时（方式 2 和 3）

方式 2 里手机连接电脑的服务器，所以这些步骤就是它需要的全部。

1. **停止服务器。**
2. **生成角色的图片更新**（每个角色一次）。在 GlobalPoint 文件夹里：
   ```bash
   node scripts/build_cn_patch.cjs 1.4.900 <最新版本> <角色文件夹>/art_files.json
   ```
   `<最新版本>` 是 `.cdn/cn_patches/patches.json` 里最后一个 `"version"`。新更新的编号要远高于它，也要高于游戏自己的版本（标题画面上的 **ResVer**），
   例如高 50。手机会用接下来的编号生成自己的更新，所以要留出空间。把这个编号写进角色文件的 `"art": { "patch": … }`，好让提示信息能说出它。
3. **加入角色文件：** 把 `custom_unit.json` 复制为 `assets/custom_units/<id>.json`（例如 `111907.json`）。
4. **启动服务器。** 它会发现新角色并自动重建游戏更新。日志会显示：
   - `[custom units] 111907 Haruhi (GP Test)`：服务器认得这个角色；
   - `Custom units: 111907 Haruhi (GP Test) (1 of 1, rows in 19 tables)`：游戏更新里有它。

   如果显示 `Custom unit 111907 skipped: … files aren't in the game files yet`，说明缺少第 2 步的图片更新。
5. **打开游戏。** 它会在标题画面下载一个小更新。然后发送或抽取这个角色（见下文）。

### 手机或模拟器，从电脑复制（方式 1）

1. 先完成上面电脑上的步骤，并确认电脑日志里的那几行。
2. 启动电脑的服务器，让手机能连上（`LISTEN_HOST="0.0.0.0"`，同[从电脑复制数据](INSTALL.zh-CN.md#改从电脑复制数据)）。
3. 在 **StarPoint Companion** 里点 **游戏数据**，然后 **从电脑下载**，并勾选 **游戏更新**：它会带来角色的图片更新。角色文件不论勾选什么都会一起带来。
   （除非你想用电脑上的存档替换手机上的，否则不要勾选 **我的存档**。）
4. 回到主界面，服务器启动后会发现新角色并重建它自己的游戏更新（一两分钟）。其他什么都不用做。
5. **确认成功：** StarPoint Companion 的日志显示 `[custom units] 111907 Haruhi (GP Test)` 和「rebuilding the CN schedule update」。打开游戏：它会在标题画面
   下载一个小更新。然后发送角色（见下文）：它会出现在邮件里，并显示在你的角色列表中。

如果忘了勾选 **游戏更新**，手机会暂时不加入这个角色。勾上再复制一次：手机随后会自动重建。

### 没有电脑的手机或模拟器（方式 1）

**不支持。** OBB 和数据包从不带自制角色，StarPoint Companion 自己也不能添加角色文件。你需要用一次电脑来复制。之后角色就留在手机上（它的文件和图片在
StarPoint Companion 更新和导入存档后都会保留）。

### 在模拟器上

- **方式 3 的模拟器** 连接电脑的服务器：电脑上的步骤就是它需要的全部。
- **运行 StarPoint Companion 的模拟器**（方式 1）和手机一样：从电脑复制。

### 发送和抽取

- **发送：** 在控制台的 **邮件** 标签页，把角色（输入它的 id，例如 `111907`）以 **一次**、**现在** 发送（[定时邮件](DASHBOARD.zh-CN.md#定时邮件)）。在游戏里打开
  **邮件** 领取。游戏下载了含有这个角色的更新之后才能发送，否则游戏会以 C8601 停止。
- **抽取：** 在角色文件的 `"banners"` 里列出扭蛋 id（例如 `["1613"]`），然后重启服务器。之后这个角色会从这些扭蛋里掉落，概率和同稀有度的其他角色一样。
  扭蛋的概率画面不会列出它。可抽取角色的 id 第一位必须与稀有度一致（1 = 5★，2 = 4★……）。

### 安全地移除角色

存档里有服务器或游戏不再认得的角色时，会以 **C8601** 失败。所以 **先把这个角色从每个有它的存档里移除**，在保存这个存档的服务器上操作（手机自己的存档
在手机上：从 StarPoint Companion 打开控制台）：

1. 关闭游戏。
2. 在控制台打开 **玩家** > 那个玩家，在 **移除角色** 下输入角色的 id，按 **从存档中移除**（会要求确认）。想留一份的话先下载存档。
   它会移除角色及其等级、玛纳板和好感度。也会把它从你的队伍里移出（它当队长的队伍会换成主角或别的角色当队长：队伍不能没有队长）、主界面、喜爱角色、
   积分挑战和 Rush 记录、道具记录和未领取的邮件中移除。装备和能力魂珠保留。
3. 对每个有它的玩家都这样做。

然后在电脑上删除 `assets/custom_units/<id>.json` 并重启服务器。手机上，再从电脑复制一次：手机会删除电脑上已经没有的角色文件。图片更新可以保留。

（保留这个角色也没关系：它不会造成任何问题。）

### 故障排除

- **「数据不足，返回标题画面」**（资源恢复），或 **错误 8100**：设备上缺少角色的某个文件。服务器的请求日志（`logs/cn_requests.log`；手机上在
  StarPoint Companion 的服务器文件夹里，可用 adb 读取）里有一行 `notify_asset_recovery 未找到素材 <文件>` 指出是哪个文件。通常是设备上没有图片更新：电脑上
  检查第 2 步；手机上勾选 **游戏更新** 再复制一次。如果图片更新在，说明角色的 `art_files.json` 少了这个文件：带上它重新制作角色。
- **C8003**「…pixelart/special 的影像短片尚未加载」（动画未加载）：角色的某个动画文件里仍然写着它复制来源的角色。角色制作工具会改名这些；用它重新制作角色。
- **C8601**「指定的Key不存在」：游戏缺少角色的某一行。通常是：
  - 游戏还没有下载含有这个角色的更新：重启游戏，并确认服务器日志显示 `Custom units: <id>`；
  - 角色被移除了，但还有存档持有它（见上文）；
  - 角色文件损坏，例如它的玛纳板节点 id 错误：服务器会跳过这样的文件，并记录 `[custom units] skipped: …` 及原因。

  出现 C8601 之后游戏会删除它那张表的副本；下一次更新会放回来。修好原因后重启服务器，让它重建。

## 修改已有的角色

自制角色文件只用于新角色。要修改游戏里已有的角色（它的能力、队长特性、数值、技能槽、名称、称号、介绍、职业、职责，或技能做什么），请用控制台的
**角色编辑器**（[UNIT_EDITOR.zh-CN.md](UNIT_EDITOR.zh-CN.md)；技能见 [SKILL_GUIDE.zh-CN.md](SKILL_GUIDE.zh-CN.md)）。它对自制角色也有效：修改会写进角色自己的文件，
编辑过的技能脚本会随每次游戏更新发出。编辑器会检查游戏能读取什么、保存修改文件并替你重建游戏更新，电脑上或 StarPoint Companion 里都可以。其他行或角色的
新图片，见 [MAKING_UNITS.zh-CN.md](MAKING_UNITS.zh-CN.md#手动修改已有角色)。
