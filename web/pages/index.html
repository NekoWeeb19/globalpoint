Multiplies the items, materials, mana and EXP that quests drop, and event drops. 1x is the base game's amounts; raise it to make the game less grindy. Reward campaigns and boosts still multiply on top. Applies from the next quest you finish.

Play on a phone over Wi-Fi

Download a connection file, then put it on the phone in Android/obb/com.leiting.wf/ (the same folder as the OBB). The game (build 23 or newer) then connects to this PC over Wi-Fi, with no cable or adb. Close and reopen the game after adding or changing it; the title screen shows which server it's on. Delete the file to go back to normal.

This server only accepts connections from this PC right now. To let a phone in, set this in the .env file and restart the server (and allow it if Windows asks about the firewall):

LISTEN_HOST="0.0.0.0"
Download phone connection file

If there's more than one, pick the one starting with 192.168 or 10. The phone must be on the same Wi-Fi.

BANNER_ROTATION="true"
BANNER_ROTATION_HOURS="24"
