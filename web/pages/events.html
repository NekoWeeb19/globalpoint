Event schedule

Move any event to new dates. Its quests, missions, shop, tokens and help pages move with it. Times are in UTC, on the server's calendar.

The game picks up a change the next time it logs in: close and reopen it, and it downloads the new dates.

      Start them all at the same moment. Each one keeps its own original length.
