Unit editor

Change what a unit's abilities do and its numbers. Saving writes a change file and rebuilds the CN game update; close and reopen the game to get it. Phones get it with Download from PC. Reset gives the game's own kit back. No unit ids change, so saves are never at risk.

Advanced mode offers every trigger, condition and effect the game can read. Anything CN's own units don't use is untested.
